# AI Study Assistant

## Description
An AI-powered Study Assistant developed using Python and Google's Gemini AI. It helps students learn more effectively through AI-generated answers, text summarization, concept explanations, quizzes, and Python coding assistance.

## Features
- AI-powered question answering
- Text summarization
- Beginner-friendly concept explanations
- Automatic quiz generation
- Python coding assistance

## Technologies Used
- Python
- Google Gemini API
- Google Gen AI SDK
- Google Colab

## Learning Outcomes
- Understanding Generative AI
- Working with AI APIs
- Python functions and conditional statements
- Prompt engineering
- Building AI-powered applications
